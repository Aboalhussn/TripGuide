Put the Thmanyah Sans font files here (they are not committed, because the licence does not allow redistributing them):

- thmanyahsans-Regular.woff2
- thmanyahsans-Medium.woff2
- thmanyahsans-Bold.woff2
- thmanyahsans-Black.woff2

Download them from https://font.thmanyah.com. Without them the app uses system fonts.
